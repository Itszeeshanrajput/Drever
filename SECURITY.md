# Security Policy

## Supported Versions
We release patches and security fixes for the latest version on the `main` branch.

## Reporting a Vulnerability
If you discover a security vulnerability within this repository, please send an email to **itszeeshanrajput@gmail.com**.

* Please include detailed steps to reproduce the vulnerability.
* Do **not** open a public GitHub issue for sensitive security vulnerabilities.
* You will receive an acknowledgment within 48 hours, followed by updates on the fix and coordinated disclosure.
